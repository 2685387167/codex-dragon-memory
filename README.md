# 龙娘人设与记忆

一个本机运行的 Codex 插件。它在 Codex 桌面侧栏提供中文面板，可编辑全局人设卡、管理全局记忆并设置自动记忆。

## 安装

把本仓库链接发给能操作本机终端的 GPT，并说「下载并安装该插件」。完整步骤和安装结果的核对方法见 [安装说明](INSTALL.md)。

手动安装时，在仓库根目录运行 `python install.py`。需要 Python 3.11 或更新版本、Codex CLI，以及支持 MCP Apps 全局入口的 Codex 桌面客户端。

打开新的 Codex 聊天，输入「打开龙娘人设与记忆管理面板」。也可以在侧栏的「探索 → 自定义」中固定该入口。客户端刚加载本地插件时，可以重新打开 Codex 以刷新侧栏。

## 人设和记忆

- **人设卡**编辑当前生效的全局 `AGENTS.md` 或 `AGENTS.override.md`。保存时备份上一版，新聊天读取更新后的文件。
- **全局记忆**保存跨项目适用的长期偏好和约定。面板支持搜索、新增、编辑和逐条删除。
- **项目记忆**由聊天中的工具写入已确认的项目根目录下的 `.codex/项目记忆.md`。每个项目维护自己的存档。
- **自动记忆**由当前对话提炼已确认且可复用的信息。「全局记忆」页的开关控制自动写入全局库与项目存档，手动保存独立可用。

## 让新聊天自动使用记忆

可以将下面两句工作流加入自己的全局 `AGENTS.md`。文件默认位于 `~/.codex/`，也可随 `CODEX_HOME` 移动。

> 新聊天首轮、切换项目或需要既有背景时，使用龙娘人设与记忆插件的 `recall_memory`。只有在确认项目根目录时才传入 `project_root`。
>
> 对话确认可长期复用的新信息时，使用 `record_memory` 自动记录，传入 `automatic: true`。通用偏好选择 `global`，项目内容选择 `project` 并传入已经确认的项目根目录。

如希望统一用这个插件记录，可在 Codex 的「设置 → 个性化」关闭内置记忆。

## 文件与数据

`plugin/app/` 包含面板和本机 MCP 服务，`plugin/skills/` 包含聊天技能与命令行工具。面板与命令行使用同一份本地数据。

首次安装后，资料由使用者在本机建立。全局库与人设备份位于 `$CODEX_HOME/dragon-memory/`，项目存档位于各自的项目目录。插件通过本机标准输入输出与 Codex 通信，保存的记录会在对话需要时由 Codex 读取。

更新时，在最新检出的仓库根目录重新执行 `python install.py`。禁用和卸载可以在 Codex 插件页完成，数据仍保存在上述位置。
